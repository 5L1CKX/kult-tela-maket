# Документация к макету сайта «Культ тела»

## Что это такое

Это верстка и функциональный макет нового сайта для салона эстетики «Культ тела» (г. Батайск). Макет собран для презентации и согласования дизайна с заказчиком. 

Все целевые кнопки (онлайн-запись, звонок, чаты, покупка сертификатов) сейчас работают в демонстрационном режиме: вместо перехода выводят информационный тост о том, что должно произойти. Фотографии в макете — временные градиентные заглушки с подписью, что будет на фото, подготовленные под замену реальными снимками с интерьерной съёмки.

Опубликованная демо-версия на GitHub Pages: https://5l1ckx.github.io/kult-tela-maket/

---

## Страницы

В макете 5 страниц:

- `index.html` — главная: позиционирование, основатель-чемпион, популярные услуги, мастера, акции, отзывы клиентов, контакты и карта.
- `uslugi.html` — общий каталог услуг с ценами и мгновенным фильтром по категориям (тело, лицо, спа, коррекция).
- `usluga-premium.html` — посадочная страница флагманской процедуры «Premium-массаж» на 2,5 часа с послемассажным сном и таймингом.
- `mastera.html` — каталог мастеров: квалификация, специализация, членство в профильных ассоциациях и кнопка записи к конкретному специалисту.
- `sertifikaty.html` — витрина подарочных сертификатов: номиналы, готовые программы, условия действия и доставка.

## Как запустить локально

### Вариант 1. Быстрый просмотр
Просто открыть `index.html` двойным кликом в файловом менеджере. Всё работает из коробки через относительные пути, сторонние сборщики не требуются.

### Вариант 2. Локальный веб-сервер (рекомендуется)
Поднять статический сервер прямо из папки `maket`, чтобы корректно отрабатывали URL-хэши, query-параметры и пути:

#### Windows
```powershell
py -m http.server 8765
```
Если утилита `py` не найдена, выполнить:
```powershell
python -m http.server 8765
```
После запуска открыть в браузере: `http://localhost:8765`  
*Где взять Python на Windows:* установить через `winget install Python.Python.3.12` или скачать официальный инсталлятор с python.org (обязательно отметить галочку «Add python.exe to PATH»).

#### macOS
```bash
python3 -m http.server 8765
```
После запуска открыть: `http://localhost:8765`  
*Где взять Python на macOS:* установить через Homebrew (`brew install python`) или накатить командные инструменты Xcode (`xcode-select --install`).

#### Ubuntu / Debian
```bash
python3 -m http.server 8765
```
После запуска открыть: `http://localhost:8765`  
*Где взять Python на Ubuntu:* выполнить в терминале `sudo apt update && sudo apt install python3`.

## Как включить кнопки («боевой режим»)

Режимом работы управляет конфигурационный файл `assets/js/config.js`.

В начале файла переключите флаг `live`:
```javascript
window.SITE_CONFIG = {
  live: true, // вместо false
  ...
};
```

Что меняется при `live: true`:
1. На тег `<html>` устанавливается атрибут `data-live="true"`. Через CSS-правила скрываются верхняя плашка «Макет дизайна» и все вспомогательные пометки с классом `.demo-only`.
2. Элементы с атрибутом `data-action` перестают блокировать клики и показывать всплывающие тосты. Скрипт проставляет в атрибут `href` реальные URL-адреса из конфига (для внешних ссылок добавляются `target="_blank"` и `rel="noopener"`).

### Быстрая проверка без правок кода
Боевой режим можно активировать через GET-параметр в строке браузера:
- `http://localhost:8765/?live=1` — принудительно включает боевой режим.
- `http://localhost:8765/?live=0` — принудительно возвращает демонстрационный режим с плашкой и тостами.

## Таблица data-action

Все интерактивные элементы в разметке размечаются атрибутом `data-action`. Ниже описано, как скрипт резолвит каждый тип действия:

| data-action | Что делает | Источник данных в config.js | Примечания и параметры |
| :--- | :--- | :--- | :--- |
| `book` | Открывает онлайн-запись YClients | `booking.base` или `booking.deepLink` | Поддерживает `data-service` и `data-master`. Подробности сборки ссылки см. ниже. |
| `call` | Инициирует телефонный звонок (`tel:...`) | `contacts.phone` | Номер без пробелов и скобок: `+79287513414` |
| `whatsapp` | Открывает чат WhatsApp (`https://wa.me/...`) | `contacts.whatsapp` | Номер в международном формате без плюса |
| `telegram` | Открывает профиль в Telegram (`https://t.me/...`) | `contacts.telegram` | Юзернейм без `@` |
| `vk` | Открывает группу ВКонтакте (`https://vk.com/...`) | `contacts.vk` | Короткое имя группы или паблика |
| `certificate` | Переход к покупке сертификата | `certificates.url` | Ссылка на страницу виджета сертификатов YClients |
| `subscription` | Переход к покупке абонемента | `subscriptions.url` | Ссылка на покупку абонементов YClients |
| `map` | Открывает адрес салона на картах | `maps[provider]` | Провайдер задается через `data-provider="yandex"` (дефолт) или `data-provider="gis"` |
| `reviews` | Открывает карточку организации с отзывами | `reviews[provider]` | Провайдер через `data-provider="yandex"` (дефолт) или `data-provider="gis"` |
| `page` | Переход на внутреннюю страницу | Берет значение из атрибута `data-href` | В демо-режиме показывает тост, в live-режиме совершает переход по указанному URL |

### Как собирается ссылка на запись YClients (действие book)

Логика сборщика ссылки в `app.js` (`bookingUrl`):
1. Скрипт считывает атрибуты элемента:
   - `data-service="<код_услуги>"` — сопоставляется со словарём `SITE_CONFIG.booking.services`.
   - `data-master="<код_мастера>"` — сопоставляется со словарём `SITE_CONFIG.booking.masters`.
2. Если найден числовой ID мастера `m` и/или услуги `s`, формируется параметр вида:
   `o = (m ? "m" + m : "") + (s ? "s" + s : "")` (например: `m12345s67890` или просто `s67890`).
3. Если параметр `o` не пустой, он подставляется в шаблон `booking.deepLink`:
   `https://n126888.yclients.ru/?o={o}` → `https://n126888.yclients.ru/?o=m12345s67890`.
4. Если оба ID равны `null` или атрибуты не были указаны, скрипт возвращает базовую ссылку на филиал из `booking.base` (`https://n126888.yclients.ru/`).

В текущем макете все ID в `booking.services` и `booking.masters` выставлены в `null`. Для запуска записи их нужно выгрузить из личного кабинета YClients салона и прописать в конфиг.

## Как добавить услугу или мастера

### Добавление новой услуги
1. В `assets/js/config.js` добавьте ключ услуги и её ID из YClients:
   ```javascript
   SITE_CONFIG.booking.services = {
     ...
     my_new_massage: 9876543
   };
   ```
2. В HTML-коде кнопки или карточки укажите соответствующие атрибуты:
   ```html
   <a href="#" class="btn btn-primary" data-action="book" data-service="my_new_massage" data-title="Новый авторский массаж">
     Записаться
   </a>
   ```
   Атрибут `data-title` используется в демо-режиме для текста во всплывающем тосте.

### Добавление нового мастера
1. В `assets/js/config.js` добавьте ключ мастера и его ID из YClients:
   ```javascript
   SITE_CONFIG.booking.masters = {
     ...
     ivanov: 112233
   };
   ```
2. В разметке свяжите кнопку с мастером:
   ```html
   <a href="#" class="btn btn-outline" data-action="book" data-master="ivanov" data-title="Запись к Иванову">
     Выбрать мастера
   </a>
   ```
   Если нужно направить клиента к конкретному мастеру на конкретную услугу, атрибуты можно объединить:
   ```html
   <a href="#" data-action="book" data-master="ivanov" data-service="my_new_massage">Записаться</a>
   ```

## Акции со сроком (data-until)

Для блоков временных спецпредложений используется атрибут `data-until="ГГГГ-ММ-ДД"`:

```html
<div class="promo-card" data-until="2026-12-31">
  Скидка 15% на первое посещение до конца года!
</div>
```

Скрипт `app.js` при загрузке сравнивает дату из атрибута с текущим системным днём (с точностью до конца суток `23:59:59`). Если акция истекла, элементу автоматически выставляется атрибут `hidden = true`, и блок исчезает со страницы.

## Палитры и тема оформления

Все цветовые переменные изолированы в файле `assets/css/tokens.css`.

В макет вшиты 3 готовые палитры:
- `kult` (выбрана по умолчанию) — фирменная палитра: глубокий сливовый акцент, тёплый песочный фон, латунь.
- `olive` — природная оливковая гамма с теплыми древесными тонами.
- `iris` — холодный ирис с лазурным акцентом и чистым светлым фоном.

Каждая палитра полностью описана для двух тем: светлой (`light`) и тёмной (`dark`). 

Состояние темы (`kt-theme`) и палитры (`kt-palette`) сохраняется в `localStorage` пользователя. При первом входе тема определяется по системным настройкам ОС (`prefers-color-scheme`).

Все цвета в `main.css` и `pages.css` задаются только через CSS-переменные: `--bg`, `--bg-2`, `--bg-3`, `--border`, `--text`, `--muted`, `--accent`, `--accent-2`, `--on-accent`, `--ph-a`, `--ph-b`.

### Как добавить свою цветовую палитру
1. В `assets/css/tokens.css` добавить два селектора (для светлой и тёмной темы):
   ```css
   :root[data-palette="amber"] {
     --bg: #FAF6F0;
     --bg-2: #FFFFFF;
     --bg-3: #F2ECE1;
     --border: #E5DACB;
     --text: #26211A;
     --muted: #6E6559;
     --accent: #C26A1B;
     --accent-2: #8F5521;
     --on-accent: #FFFFFF;
     --ph-a: #F3E6D5;
     --ph-b: #EFE8DC;
   }

   :root[data-palette="amber"][data-theme="dark"] {
     --bg: #181512;
     --bg-2: #211D19;
     --bg-3: #2B2520;
     --border: #3D352E;
     --text: #EFE9E2;
     --muted: #A3998E;
     --accent: #E08938;
     --accent-2: #C48750;
     --on-accent: #181512;
     --ph-a: #2E251E;
     --ph-b: #2A241E;
   }
   ```
2. В шапку страниц внутри выпадающего списка `[data-palette-menu]` добавить пункт выбора:
   ```html
   <button type="button" role="menuitemradio" data-palette-value="amber">Янтарная</button>
   ```

## Карта потока данных

Архитектура макета разделена по слоям, чтобы исключить мерцание стилей (FOUC) и сохранить независимость разметки от логики:

1. `config.js`  
   Служит единым источником правды. Объявляет глобальный объект `window.SITE_CONFIG`: контактные данные, базовые URL и deep link YClients, карты, отзывы, словарь ID услуг и мастеров, текст демо-уведомлений.

2. `theme-init.js`  
   Подключается в `<head>` перед стилями. Выполняется синхронно до первичной отрисовки DOM:
   - Читает сохраненную тему (`kt-theme`) или проверяет `matchMedia`.
   - Читает палитру (`kt-palette`) из `localStorage`.
   - Проверяет query-параметр `?live=1` или `?live=0` и флаг `SITE_CONFIG.live`.
   - Выставляет на тег `<html>` атрибуты `data-theme`, `data-palette` и `data-live`. Благодаря этому страница сразу красится в нужные цвета без задержек и вспышек белого фона.

3. `tokens.css`  
   Подхватывает атрибуты `data-palette` и `data-theme` на элементе `<html>` и инициализирует CSS-переменные для сетки, скруглений, теней и текущей цветовой гаммы.

4. `main.css` + `pages.css`  
   `main.css` содержит сброс, типографику, базовые элементы, шапку, подвал и сквозные компоненты. `pages.css` подключается только на внутренних страницах и описывает специфичные секции каталога, карточки мастеров и страницу сертификатов.

5. `app.js`  
   Подключается в самом конце `<body>` и оживляет разметку:
   - `fillContacts()`: находит элементы `[data-contact]` и подставляет номера, ссылки и адрес из `SITE_CONFIG.contacts`. Заполняет текущий год в `[data-year]`.
   - `wireActions()`: вешает обработчики на `[data-action]`. В режиме макета перехватывает клик и показывает тост; в боевом режиме проставляет настоящие `href` через функции-резолверы.
   - `wireExpiring()`: находит блоки `[data-until]` и скрывает те, срок которых уже прошёл.
   - `wireTheme()`: обрабатывает переключатель темной/светлой темы (`[data-theme-toggle]`) и меню выбора палитры (`[data-palette-root]`), сохраняя выбор в `localStorage`.
   - `wireMenu()`: мобильное бургер-меню (`[data-burger]`, `[data-mobile-nav]`).
   - `wireFilters()`: клиентская фильтрация каталога (`[data-filter-group]`) по тегам `[data-tags]`, синхронизирует состояние с хэшем в URL (`#face`, `#spa` и т.д.).
   - `wireReveal()`: появление секций при скролле через `IntersectionObserver` для элементов с классом `.reveal`.

## Что осталось до боевого сайта

Список задач для доведения макета до полноценного боевого запуска:

1. **Реальные фотографии**: заменить градиентные заглушки качественными снимками кабинетов, зоны отдыха, кедровой бочки, процесса массажа и портретами мастеров.
2. **Рейтинги и отзывы**: заменить демонстрационные тексты (помеченные классом `demo-note`) на настоящие выгрузки и прямые ссылки на отзывы в Яндекс Картах и 2ГИС.
3. **График работы и парковка**: уточнить точный режим работы салона и добавить понятную схему проезда / ориентиры по парковке на Ворошилова.
4. **Надбавка за категорию**: согласовать и зафиксировать процент или сумму надбавки при записи к топ-мастеру / основателю.
5. **Идентификаторы YClients**: прописать в `config.js` реальные числовые ID для каждой услуги в `booking.services` и для каждого мастера в `booking.masters`.
6. **Юридическая документация**: подготовить и сверстать страницы «Политика конфиденциальности» и «Публичная оферта», привязать согласие на обработку персональных данных.
7. **Локализация шрифтов**: скачать файлы гарнитур Cormorant Garamond и Manrope в `assets/fonts/` и подключить через `@font-face` вместо внешних запросов к Google Fonts.
8. **Перенос на Astro**: перевести статическую сборку на фреймворк Astro для автоматической генерации отдельных посадочных страниц под каждую услугу из каталога для SEO-продвижения.
